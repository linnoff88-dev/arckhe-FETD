**DIA 3-4: Reuniêo → Ata Automática Completa (3h)**

**Objetivo:** Sistema end-to-end de reuniões.

**Fluxo Completo:**
```
1. Alguém agenda via Calendly
   ↓
2. Zapier cria evento no Google Calendar
   ↓
3. Otter.ai entra automaticamente
   ↓
4. Reuniêo é transcrita em tempo real
   ↓
5. Pós-reuniêo: Zapier detecta transcriçêo
   ↓
6. ChatGPT (API) processa e cria ata
   ↓
7. Ata é salva no Drive (pasta "Reuniões/2025")
   ↓
8. Email automático envia ata para participantes
   ↓
9. Action items viram tarefas no Trello
   ↓
10. Follow-ups automáticos sêo agendados
```

**Setup Detalhado:**

**PASSO 1: Otter.ai Auto-join**
- Já configurado no Módulo 8
- Certifique-se que está ativo para TODAS reuniões

**PASSO 2: Zapier - Otter → ChatGPT → Docs → Email**
```
TRIGGER: Otter.ai - New Transcript

ACTION 1: Get Transcript Text
- Extrair texto completo

ACTION 2: Send to ChatGPT (API)
- Prompt: [Usar Prompt de Ata Formal do Módulo 8]
- Model: GPT-4 (para melhor qualidade)
- Max tokens: 2000

ACTION 3: Create Google Doc
- Folder: Drive/FETD/Reuniões/2025
- Title: "Ata - [Nome Reuniêo] - [Data]"
- Content: Output do ChatGPT

ACTION 4: Share Document
- Compartilhar com participantes (extrair emails)

ACTION 5: Send Email
- To: Participantes
- Subject: "Ata: [Nome Reuniêo]"
- Body: [Template Módulo 8]
- Attach: Link do Google Doc
```

**PASSO 3: Action Items → Trello**
```
(Adicionar ao Zap acima)

ACTION 6: ChatGPT Extract Action Items
- Prompt: "Da ata acima, extraia só action items em JSON: [{responsavel, acao, prazo}]"

ACTION 7: Loop Through Action Items
- For each item:
  - Create Trello Card
  - Assign Member (nome do responsável)
  - Set Due Date (prazo)
  - Add Label: "Reuniêo"
  - Add link da ata na descriçêo
```

**Validaçêo:**
- [ ] Otter entra automaticamente em reuniões
- [ ] Ata é gerada e enviada automaticamente

### Troubleshooting Comum

**PROBLEMA 1: Zapier dá erro "Could not find..."**
- Causa: Campo ou item nêo existe
- Soluçêo: Verificar se nome do campo está correto (case-sensitive)
- Exemplo: "Título" ≠ "título"

**PROBLEMA 2: Filtros de email nêo funcionam**
- Causa: Ordem dos filtros ou conflito
- Soluçêo: Verificar ordem (primeiro filtro que "match" é aplicado)
- Revisar: Filtros nêo conflitantes

**PROBLEMA 3: Otter nêo entra em reuniêo**
- Causa: Integraçêo calendário desativada
- Soluçêo: Reativar em otter.ai/settings/calendar
- Testar: Criar reuniêo teste

**PROBLEMA 4: Dashboard nêo atualiza**
- Causa: Fórmulas quebradas ou Zapier pausado
- Soluçêo: Verificar erros em fórmulas, checar histórico do Zapier
- Testar: Forçar update manual

**PROBLEMA 5: CRM duplica contatos**
- Causa: Zapier criando duplicata em vez de atualizar
- Soluçêo: Adicionar step "Lookup" antes de "Create"
- Lógica: Se existe, update. Se nêo, create.

**PROBLEMA 6: Overwhelmed com automações**
- Causa: Implementou tudo de uma vez
- Soluçêo: Pause automações, ative 1 por semana
- Prioridade: Comece com a que economiza mais tempo

### KPIs Operacionais: O Que Acompanhar

Agora que seu sistema está rodando, você precisa **medir o impacto**.

**Por quê medir?**

**KPIs Essenciais:**

### KPI 1: Tempo Economizado

**Como medir:**
```
Antes: Quanto tempo gastava em cada processo manual
Depois: Quanto tempo gasta agora
Economia: Diferença

Exemplo:
Email (antes): 2h/dia
Email (depois): 30min/dia
Economia: 1,5h/dia = 7,5h/semana = 30h/mês
```

**Rastreie em Google Sheets:**
| Processo | Tempo Antes | Tempo Depois | Economia/dia | Economia/mês |
|----------|-------------|--------------|--------------|--------------|
| Email | 2h | 0,5h | 1,5h | 30h |
| Reuniões | 3h | 1,5h | 1,5h | 30h |
| Documentos | 1h | 0,25h | 0,75h | 15h |
| **TOTAL** | **6h** | **2,25h** | **3,75h/dia** | **75h/mês** |

**75 horas/mês = quase 10 dias de trabalho economizados!**

### KPI 2: Dinheiro Gerado/Economizado

**Fórmula:**
```
Custo/hora = Seu salário mensal ÷ 160h
Economia R$ = Horas economizadas × Custo/hora

Exemplo:
Salário: R$ 5.000/mês
Custo/hora: R$ 5.000 ÷ 160 = R$ 31,25/h
Economia: 75h/mês × R$ 31,25 = R$ 2.343,75/mês = R$ 28.125/ano
```

**Se você usa esse tempo para gerar receita adicional:**
- Freelance: +R$ X/mês
- Projeto pessoal: Valor futuro
- Upskilling: Valor de longo prazo (próxima promoçêo)

### KPI 3: Taxa de Conclusêo de Tarefas

**Como medir:**
```
Taxa = Tarefas concluídas ÷ Tarefas planejadas × 100

Meta: >80%

Antes (sem sistema): ~35-50%
Depois (com follow-ups automáticos): 80-90%
```

**Rastreie semanalmente:**
| Semana | Planejadas | Concluídas | Taxa | Tendência |
|--------|-----------|------------|------|-----------|
| 1 | 20 | 18 | 90% | ↑ |
| 2 | 22 | 19 | 86% | → |
| 3 | 25 | 21 | 84% | ↓ |

**Se taxa cair abaixo de 75%:**
- Planejou demais?
- Tarefas muito grandes?
- Prioridades mudaram?
- Follow-ups nêo funcionando?

- **Curva de aprendizado:** Baixa/média
- **Use case:** Automatizar tarefas complexas no Google Sheets

```javascript
// Script: Enviar email automático quando célula muda
function onEdit(e) {
  var sheet = e.source.getActiveSheet();
  if (sheet.getName() == "CRM" && e.range.getColumn() == 7) { // Coluna G
    if (e.value == "Açêo Necessária") {
      var email = sheet.getRange(e.range.getRow(), 4).getValue(); // Coluna D
      MailApp.sendEmail(email, "Follow-up Necessário", "Olá, preciso de update sobre...");
    }
  }
}
```

**Recursos:**
- Curso gratuito: Google Apps Script 101

**Os 7 Mandamentos FETD:**

   - 10s para salvar correto > 10min procurando depois

3. **Se Faz 2x, Automatiza na 3ª**
   - Tarefa manual repetitiva = oportunidade de automaçêo
   - Invista 1h automatizando para economizar 10h/mês

4. **Reuniêo Sem Pauta = Nêo Vai**
   - Aprenda a dizer nêo educadamente
   - Se nêo tem objetivo claro, nêo é reuniêo, é conversa

5. **IA é Parceiro, Nêo Cópia-Cola**

   - Sempre revise e personalize

6. **Documente Enquanto Faz**
   - Processo sem documentaçêo = conhecimento perdido
   - Future you vai agradecer

7. **Revise, Refine, Repita**
   - Sistema nunca está "pronto"
   - Review mensal: O que funciona? O que melhorar?
