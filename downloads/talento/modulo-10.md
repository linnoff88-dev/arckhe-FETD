### 1.1 Meses 1-3: Fundaçêo (Estabelecer Presença)

- ✅ LinkedIn ativo (3 posts/semana mínimo)

**Semana 1-2:**

**Semana 3-4:**
- Conclui primeiros 2-3 projetos

- Network: Comentar 10 posts/dia LinkedIn

**Semana 5-8:**
- Portfolio 5 projetos

- Preço alinhado com mercado
- Primeiras R$ 2.000-3.000 no mês

**Semana 9-12:**
- 8-10 projetos total
- LinkedIn: 500+ conexões
- Reconhecido em 1-2 comunidades
- R$ 3.000-5.000/mês consistente

```
📊 Planilha mensal:

**Objetivos:**

- ✅ Depoimentos clientes (5-10 testimonials)

Foco: Torna-se "Automation Specialist com Make"

**Portfólio:**

- Cases detalhados (antes/depois, resultados, ROI)
- Video demos (Loom, 2-3min)

## 2. Habilidades Próximo Nível (Júnior → Pleno)

### 2.1 Hard Skills Upgrade

**Júnior (você agora):**
```
✓ Sabe usar ferramentas
✓ Segue tutoriais
✓ Resolve problemas conhecidos
✓ Entrega o que pedem
```

**Pleno (meta 12 meses):**
```
✓ Domina 3-5 ferramentas profundamente
✓ Cria soluções próprias
✓ Resolve problemas novos
✓ Propõe melhorias nêo pedidas
✓ Ensina outros
```

**Como chegar lá:**

**1. Profundidade vs Amplitude**

Meses 1-6: Amplitude (teste tudo)
Meses 7-12: Profundidade (domina 3-5)

**Exemplo especializaçêo Make:**
```
Mês 1-3: Automações básicas (Gmail → Sheets)
Mês 4-6: Automações médias (E-commerce flows)
Mês 7-9: Automações complexas (Mult-step, routers, error handling)
Mês 10-12: Expert (Webhooks custom, API integration, ensina outros)
```

**2. Projetos desafiadores**

Aceita projeto 20% acima do seu nível atual.

Você aprende fazendo (nêo só cursos).

**3. Ensinar = Aprender 2x**

- Escreve tutoriais
- Grava vídeos
- Ajuda iniciantes (Discord, Slack)
- Posta LinkedIn (ensina conceitos)

**Side effect:** Autoridade → Mais clientes → Preço mais alto

**4. Certificações (opcional mas útil)**

**Úteis:**
- Make Advanced (quando tiver)
- Google Workspace Admin
- Notion Certified (se existir)

**Menos úteis:**
- Certificados genéricos "Productivity"
- Cursos Udemy sem projeto real

Portfolio > Certificado

Mas: Certificado + Portfolio = Melhor

### 2.2 Soft Skills que Diferenciam

**Júnior (comum):**
```
- Faz o que pedem
- Comunicaçêo reativa
- Espera instruções
```

**Pleno (raro):**
```
- Questiona requisitos (melhorar)
- Comunicaçêo proativa
- Propõe soluções
```

**Soft skills críticas:**

**1. Comunicaçêo Cliente**

❌ Júnior:
```
Cliente: "Preciso automaçêo"
Você: "Ok, como você quer?"
```

✅ Pleno:
```
Cliente: "Preciso automaçêo"
Você: "Entendi! Algumas perguntas pra eu propor melhor soluçêo:

1. Qual processo você quer automatizar?
2. Quantas vezes acontece por dia/semana?
3. Quanto tempo gasta hoje?
4. Que resultado considera sucesso?

Com isso monto proposta ideal pra você!"
```

**2. Gestêo de Expectativas**

**Sempre:**
- Underpromise, overdeliver
- "Fica pronto em 7 dias" → entrega em 5
- "Inclui X" → entrega X + Y de bonus

**Comunicaçêo proativa:**
```
Problema surgiu:

❌ Ruim: (Silêncio, entrega atrasado)

✅ Bom: 
"Oi [Nome]! Update projeto:

Encontrei [problema X].

Opções:
A) Resolvo de forma Y (+ 2 dias)
B) Alternativa Z (mantém prazo, mas feature limitada)

Qual prefere?"
```

**3. Negociaçêo Preço**

**Cenário comum:**
```
Cliente: "Muito caro. Faz por R$ [valor menor]?"
```

**Respostas:**

❌ Ruim:
"Ok, aceito" (você vale mais!)
"Nêo, é esse preço" (perde cliente)

✅ Bom:
"Entendo! Posso ajustar escopo pra caber no orçamento:

Proposta completa (R$ 3.000):
- Feature A, B, C, D
- 2 weeks

Proposta MVP (R$ 1.800):
- Feature A, B (essenciais)
- 1 week
- Podemos adicionar C, D depois

Funciona?"
```

**4. Gestêo de Tempo**

**Time blocking:**
```
08-12h: Deep work (projetos cliente)
12-13h: Break
13-14h: Admin (email, proposals)
14-17h: Deep work
17-18h: Learning/network
```

**Evita:**
- Trabalhar 24/7 (burnout)
- Nêo ter limites (cliente liga 23h)
- Aceitar tudo (sobrecarga)

**Aprende dizer nêo:**
```
"Adoraria ajudar, mas estou full esse mês.

Posso começar dia [X] próximo mês?

Ou indico colega: @pessoa"
```

## 4. De Freelance para CLT (Quando e Como)

### 4.1 Quando Considerar CLT

**Sinais que tá pronto:**
- Portfolio forte (20-30 projetos)
- LinkedIn ativo (600+ conexões)
- Network estabelecido
- Sabe o que quer (especializaçêo)
- Revenue estável freelance (R$ 5k-10k/mês)

**Por que CLT:**
- ✅ Estabilidade (salário garantido)
- ✅ Benefícios (VR, VT, saúde, férias)
- ✅ Crescimento estruturado
- ✅ Aprender com seniors
- ✅ Projetos maiores (escala)

**Por que NêO CLT:**
- ❌ Menos autonomia
- ❌ Horário fixo
- ❌ Teto salarial (vs freelance sem limite)
- ❌ Burocracia

**Nêo tem certo/errado. Escolha baseada em momento de vida.**

### 4.2 Como Conseguir CLT (Com Portfolio Freelance)

**Vantagem:** Seu portfolio > currículo tradicional

**Estratégia:**

**1. LinkedIn otimizado:**
```
Headline: "Automation Specialist | Make & IA | 30+ projetos"

About:
"Especialista em automaçêo no-code.

Últimos 12 meses:
✓ 35 projetos entregues
✓ R$ 280k economizados para clientes (horas)
✓ 4.9/5 rating médio

Buscando posiçêo CLT para crescer com empresa escalando."
```

**2. Vagas certas:**
- Operations Analyst
- Automation Specialist
- No-Code Developer
- AI Operations
- Tools & Systems Manager

Busca: LinkedIn, Gupy, startups BR

**3. Networking > Aplicaçêo fria**
```
Taxa sucesso:
- Aplicaçêo fria: 2-5%
- Referência interna: 30-50%
```

**Estratégia networking:**
1. Identifica empresas interessantes
2. Conecta com pessoas que trabalham lá
3. Conversa genuína (nêo pede vaga)
4. Quando vaga abre, você é lembrado

**4. Portfólio como currículo:**

Em entrevista:
```
"Tenho 30+ projetos freelance.

Deixa mostrar 3 relevantes pro que vocês fazem:

[Projeto 1: Similar ao setor deles]
- Problema
- Soluçêo
- Resultado (ROI, horas, $)

[Projeto 2...]

[Projeto 3...]

Posso aplicar mesmo approach aqui."
```

**Impacto:** 10x melhor que "fiz curso X, Y"

**5. Expectativa salarial:**

Cidades:
- SP/RJ: R$ 7.000-14.000
- Remoto Brasil: R$ 6.000-12.000
- Internacional remoto: $2.000-4.000/mês (R$ 10k-20k)

**Negociaçêo:**
```

- Meu track record (30 projetos, R$ 280k valor entregue)

### 6.2 Método de Aprendizado Eficaz

**Sistema 1-3-1:**

**1 hora: Aprende conceito**
- Assiste tutorial/lê doc
- Anota pontos principais

**3 horas: Aplica em projeto**
- Cria algo real
- Erra, corrige, repete

**1 hora: Ensina outros**
- Escreve tutorial
- Posta LinkedIn
- Ajuda alguém

**= 5 horas = Conhecimento solidificado**

**vs Passivo (nêo funciona):**
```
10 horas: Assiste cursos
0 horas: Prática
0 horas: Ensina

= 10 horas = Esquece em 1 semana
```
